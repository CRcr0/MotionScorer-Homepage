MotionScorer: an end-to-end driving evaluator that reads out trajectory quality from a frozen VLM 从冻结 VLM 的隐表示中读出轨迹质量的端到端驾驶评估器

The judgment is already inside the frozen driving VLM — the failure lives in the readout. nuSteering trains only a shared query bank and an affine scalar head: a pseudo-score loss fixes what to predict, a teacher-conditioned deflection criterion fixes how to read. No weight updates. No rule gates. 判断力早已存在于冻结的驾驶 VLM 内部——失灵的只是读出通道。nuSteering 只训练一组共享 query 与一个仿射标量头：pseudo-score 损失决定读什么，teacher-conditioned deflection 准则决定怎么读。不改一个权重，不设一条规则门。

The problem问题

Every existing fix rewrites the evaluator现有方案都在重写评估器本身

Driving VLMs can explain why a trajectory is unreasonable, yet their prompted numerical scores stay unstable. The field's response has been to install scoring ability — by prompting harder, routing through rules, or retraining weights. Each path gives something up: 驾驶 VLM 能解释一条轨迹为何不合理，但直接提示得到的数值分始终不稳定。领域的应对是把打分能力"装进去"——更用力地 prompt、路由回规则、或重训权重。每条路都要付出代价：

① Direct Prompting

Unstable scores分数不稳定

Ratings collapse to a few round values (≈24 effective levels); repeated queries disagree with themselves.评分坍缩到少数整数值（约 24 个有效等级）；重复询问自相矛盾。

② DriveJudge

Rule-capped被规则封顶

Semantic judgment routed through fixed rule gates — the model can excuse a penalty but never impose an unseen one.语义判断被路由回固定规则门——模型能豁免惩罚，却永远加不出规则外的新惩罚。

③ DriveCritic

Weights must move必须动权重

LoRA / SFT / RL installs the score but re-opens the backbone — forfeiting the deployed model's reproducibility.LoRA / SFT / RL 把分数装了进去，但重新打开了 backbone——部署模型的可复现性随之作废。

— MotionScorer

Read out, not installed读出，而非装入

Backbone stays frozen; a lightweight shared-query readout recovers the score from representations that already exist.backbone 全程冻结；轻量共享 query 读出通道从既有表示中恢复分数。

Core question. How much of the trajectory-quality information decodable from a frozen driving VLM's representation can be recovered through the readouts its own causal attention interface realizes? 核心问题：冻结驾驶 VLM 表示中可解码的轨迹质量信息，有多少能通过它自身因果注意力接口所能实现的读出通道恢复出来？
Method · nuSteering方法 · nuSteering

Two objectives, zero backbone changes两个目标函数，backbone 零改动

The score query's context-attention branch is exactly a weighted aggregation of frozen values — its attention weights act as filter taps, but only within the readout family the frozen model can realize. nuSteering selects the right member of that family: score query 的上下文注意力分支恰好是冻结 value 的加权聚合——其注意力权重就是滤波器抽头，但只能落在冻结模型可实现的读出族内。nuSteering 要做的是在这个族里选对成员：

1

Freeze & append冻结并附加

A shared query bank E and one score query trail the multimodal context (Qwen2.5-VL-7B, every parameter frozen). Causal masking leaves the original context untouched.共享 query 组 E 与一个 score query 追加在多模态上下文之后（Qwen2.5-VL-7B，参数全冻结）。因果掩码保证原上下文分毫不动。

the interface接口
2

Pseudo-score lossPseudo-score 损失

A rule-gated teacher auto-generates targets — no human labels, no preference pairs. This fixes what to predict, bypassing the collapsed numeric-token channel.规则门控 teacher 自动生成监督目标——无人工标注、无偏好对。它决定读什么，绕开坍缩的数字 token 通道。

what to predict预测什么
3

Teacher-conditioned deflectionTeacher 条件化 deflection

Inside the attention-filtered latent: estimate the score-aligned direction, whiten residual nuisance variation, reward readouts whose signal survives. This fixes how to read.在注意力滤波后的隐变量里：估计分数对齐方向，白化残余扰动，奖励信号存活的读法。它决定怎么读。

how to read怎么读
ρTCD(E) = ŝE⊤ D̂E−1 ŝE
signal-over-nuisance deflection, computed on the exact context-attention branch; discarded at inference — deployment is a single frozen forward pass. 信号/扰动 deflection，在精确的上下文注意力分支上计算；推理时弃用——部署就是一次冻结前向。
nuSteering The constrained-filtering view, live — contribution waveforms per latent channel, attention taps as volume knobs, the frozen attention filter plane, and the filtered output. 约束滤波视角实时演示——每个 latent 通道的贡献波形、作为音量旋钮的 attention taps、冻结注意力滤波面与过滤输出。
This is nuSteering (chapter 04 of the interactive story): a shared query handle moves every tap together inside the frozen model's realizable readout family — from a shortcut reading to an evidence reading. 这就是 nuSteering（交互式讲解第 04 章）：共享 query 手柄在冻结模型可实现的读出族内联动所有 taps——从 shortcut 读法走向证据读法。
